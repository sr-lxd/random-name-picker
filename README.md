# 随机点名与抽奖

一个 Windows 桌面小工具。它从 Excel 名单中随机抽取一人，适用于课堂点名、活动抽奖和小组任务分配。

## 功能

- 选择 `.xlsx` 名单文件，程序读取第一个工作表。
- 点击“开始”后快速滚动显示候选人；点击“确认”停止并显示结果。
- 勾选“不重复”后，已确认的人会从本轮名单中移除；继续抽取时不会再次出现。
- 点击“重置”后重新读取当前选中的 Excel 文件，开始新一轮。
- 结果区会显示该行中有值的列名和内容，方便教师或主持人确认抽取对象。
- 窗口保持在其他窗口上方，便于投屏时使用。

## Excel 名单格式

程序读取工作簿的第一个工作表。第一行是字段名称，从第二行开始是人员记录。**D 列（第 4 列）用于抽取对象**，每位参与者在这一列应有唯一且非空的姓名或编号。确认后，结果区显示该行各列信息。

仓库提供 [sample_roster.xlsx](sample_roster.xlsx) 作为可直接试用的虚构名单。它有 10 条示例记录，D 列“抽取对象”存放唯一候选人。姓名、编号和班级均为虚构内容，不对应真实学生或个人。

如需使用自己的名单，可照示例格式制作工作簿，并在程序中选择文件。不要把真实学生名单、联系方式、成绩或其他个人信息上传到公开仓库。

## 安装与运行

建议使用 Windows 10/11 和 Python 3.10 或更高版本。安装 Python 时启用 PATH，然后在项目目录打开 PowerShell：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python ".\随机抽奖点名v1.09.py"
```

依赖包括 [PySimpleGUI 6](https://docs.pysimplegui.com/documentation/installing_licensing/) 和 `openpyxl`。PySimpleGUI 官方文档说明可从 PyPI 安装；首次使用也可按其安装指南操作。

## 使用步骤

1. 启动程序，点击“名单”选择自己的 `.xlsx` 文件；也可以先选择仓库中的 `sample_roster.xlsx` 体验。
2. 确认名单第一行是字段名，D 列每行都有唯一的抽取对象。
3. 根据需要勾选或取消“不重复”。
4. 点击“开始”滚动候选人，再点击“确认”确定结果。
5. 继续抽取时，勾选“不重复”会排除已确认人员；名单抽完后点击“重置”重新开始。

## 数据与隐私

- 名单由本机程序读取，程序没有网络上传功能。
- 请自行确认对名单内容具有合法使用权限。课堂演示或活动投屏前，先检查结果区是否会显示不适合公开的信息。
- Git 忽略规则排除 Excel 工作簿，只允许提交 `sample_roster.xlsx` 这份虚构示例。提交前仍应检查暂存文件清单。
- 项目不包含真实名单或预编译的可执行文件。
